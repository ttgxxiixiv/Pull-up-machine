# Дневник подтягиваний

Интерактивный дневник тренировок по подтягиваниям: план на каждый день, запись подходов, графики прогресса, экспорт и импорт данных. Работает без интернета.

## Как открыть

Это статичное веб-приложение без сборки и зависимостей. Варианты:

1. GitHub Pages: включите Pages для ветки в настройках репозитория и откройте выданный адрес на телефоне. Затем в меню браузера выберите «Добавить на главный экран». После первого открытия приложение работает оффлайн благодаря service worker.
2. Локально: `python3 -m http.server 8000` в папке проекта и откройте `http://localhost:8000`.
3. Просто открыть `index.html` двойным щелчком. Всё работает, кроме установки как приложения (service worker требует https или localhost).

## Программа

Блок = 3 рабочие недели + разгрузочная неделя с тестом максимума. 3 или 4 тренировки в неделю (настраивается).

| День | Неделя 1 | Прогрессия |
|---|---|---|
| Объём | 6×8, отдых 2 мин, RIR 2. Не выходит 8 — 6×6 чисто | +1 повторение в неделю до 6×10, каждый новый блок +2,5 кг в рюкзаке |
| Сила | 5×5 с рюкзаком 5 кг или негативы 4–5 с | +2,5 кг за блок; негативы 4–5 → 5–6 → 6–7 с |
| Вариативность | Обратный и нейтральный хват, 5 подходов; тяга гантели 3×10–12 | +1 повторение в неделю и за блок; гантель +2 кг после 3×12 |
| Лёгкий день | Висы 3×40 с, лопаточные подтягивания 3×8 | Вис +5 с в неделю до 60 с, затем +5 кг; лопаточные 8 → 12, потом с паузой |

Разгрузка (каждая 4-я неделя): объём вдвое меньше, веса те же, один подход на максимум.

Приложение само переходит к следующему дню после сохранения тренировки, подсказывает вариант с запасом, если прошлый раз не вышел, и предупреждает, если тренировок за неделю уже 4.

## Данные

Всё хранится в localStorage браузера. В разделе «Ещё» можно скачать JSON-файл, поделиться им или скопировать текстом, а на другом устройстве импортировать. При импорте тренировки объединяются по идентификатору, дубликаты не создаются.

## Файлы

- `index.html`, `styles.css`, `app.js` — приложение
- `sw.js` — service worker, кэширует все файлы для оффлайн-режима
- `manifest.webmanifest`, `icon.svg`, `icon-maskable.svg` — установка на главный экран
